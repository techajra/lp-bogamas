# Bogamas Web

Landing page Bogamas (minyak goreng kelapa murni, Purworejo). Tombol pesan mengarah ke
WhatsApp bot toko yang dilayani alur Toko di project `../chatbot`.

```bash
npm install
npm run dev
```

Sebelum dipublikasikan, ganti `WA_NUMBER` dan harga `PRODUCTS` di
`src/components/BogamasLanding.tsx` (samakan dengan menu Toko > Produk di chatbot).
